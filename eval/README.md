# 평가 세트

브리핑 개선안이 실제로 나아졌는지 재는 고정 문항입니다. 수정 전후에 같은 입력으로 돌려 점수를 비교합니다.

- `snapshot-20261001/`: 고정 입력(수집 데이터, 장부 22줄, state, 작업 시작 2026-10-01 13:53 KST). 언제 돌려도 같은 후보 목록이 나옵니다.
- `cases.json`: 문항과 정답.
  - `prep`: 후보 목록의 표시·점수 구간 문항. 자동 채점.
  - `judge`: 수록 여부(제외·참고·핵심)·관련도 문항. 스냅샷으로 돌린 회차의 briefing.json이 있어야 채점.
  - `known_gap`: 아직 해결 못 한 알려진 공백. 회귀 판정에서 빠지고, 해결 수를 따로 셉니다.
  - `status`: `draft`는 사용자 검토 전, `reviewed`는 검토를 마친 정답.
- `score.py`: 채점기. `replay.md`: 판정 문항용 재현 실행 절차. `results/`: 재현 결과와 점수 기록.

```
python3 eval/score.py                         # 현재 build.py
python3 eval/score.py --build 다른/build.py    # 수정 전 버전과 비교
python3 eval/score.py --briefing briefing.json # 판정 문항까지
```

종료 코드 1은 일반 prep 문항 회귀입니다. 수정안은 회귀 없이(종료 0) 알려진 공백 해결 수나 판정 점수가 올라야 반영합니다.

주의
- `/tmp/ev`를 비우고 쓰므로 실제 회차와 같은 환경에서 동시에 돌리지 않습니다.
- briefing.json에 없는 후보는 "제외"로 채점합니다. 제외 문항이 많으므로 판정 점수는 참고·핵심 문항 결과와 함께 봅니다.
- 판정 문항은 기사 본문에 의존하므로 시간이 지나 원문이 바뀌거나 사라지면 다시 확인해야 합니다.
